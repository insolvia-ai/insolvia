# Architecture Decision Records

Durable decisions with their rationale — the ones that stay expensive to
re-litigate and quietly erode if nobody wrote down *why*. Shorter-lived planning
decisions live as `D<n>` entries in [`../plan.md`](../plan.md); an ADR is
where a decision graduates when it outlives the plan.

| [0009](0009-a-case-belongs-to-a-firm.md) | A case belongs to a **firm**, not to the person who opened it. Membership, roles and per-feature permissions live in **our own store**, not in Cognito claims — amending ADR 0007. Four independent axes (role / admin / all-cases / per-feature), everything fails closed, and a firm cannot be left without an administrator. | Accepted |
| [0008](0008-testing-shape-follows-the-code-it-tests.md) | Testing shape is per-area, not one house rule: pyramid over the Python services' domain layer, trophy over the UI, contract pins at the API seam, E2E deliberately scarce. Static analysis is the base layer; no coverage gate. | Accepted |
| [0009](0010-design-system-moves-to-its-own-repository.md) | The design system and design tokens leave this repo for `insolvia-ai/design-system` and are consumed as published packages. Ends the arrangement where the app read the package's source through a workspace symlink while marketing installed a published version — one package with two simultaneous truths. | Accepted |
| [0011](0011-cross-tenant-administration-is-a-separate-principal-class.md) | Provisioning firms is a separate principal class — Insolvia staff, authenticated by **Google Workspace** (direct OIDC, no staff pool), through a separate `services/admin` whose every mutation writes an append-only audit row. Amends 0001 (a second principal reaches the firm table) and carries 0009's reasoning to the new caller (firm ids in URLs are objects of audited operations, not scope claims). | Accepted |
| [0012](0012-shared-python-domain-package.md) | The firm domain, token verification, and their adapters move to `packages/insolvia_core`, installed by each Python service from a local path — one set of item shapes for every service that writes them. Admission rule: code moves in only when a second service actually imports it. | Accepted |
| [0013](0013-mcp-server-replaces-direct-pms-integration.md) | Insolvia integrates with no practice-management system directly. It exposes its case-management capability as a remote **MCP server**; the attorney's AI harness (Claude Desktop, ChatGPT, …) moves data between their PMS and us. Retires the MyCase spike; agent writes land as candidates under the confirm-before-entry invariant. | Accepted |
| [0014](0014-the-repository-is-the-regulatory-release-registry.md) | Effective-dated regulatory artifacts — form templates, government datasets, statutory dollar amounts — are committed files, ingested by PR and shipped in the reading service's deploy artifact. Merge is the release, git is the audit trail; no dataset store, no ingestion API. Carries the outgrows-the-diff revisit trigger. | Accepted |
| [0015](0015-async-pipelines-beside-the-lambdalith.md) | The Flask lambdalith stays for the synchronous API; minutes-long work (packet assembly, AI review, extraction) runs in **async pipelines** of image-packaged worker Lambdas beside it. Every Lambda is image-packaged; SAM rejected — Terraform stays the only IaC. | Accepted — primitive chosen in [0018](0018-sqs-queue-and-worker-lambda-over-step-functions.md) |
| [0016](0016-mcp-server-is-its-own-service.md) | The MCP server is its own service, `services/mcp` — own Lambda, image, and hostname — not routes inside `services/api`. A different protocol with its own server obligations, disjoint token audiences, and agent-shaped blast radius; the case domain moves to `insolvia_core` when the new service first imports it, per 0012's admission rule. | Accepted |
| [0017](0017-launch-states-florida-texas-georgia.md) | Schedule C launches with the federal §522(d) scheme plus **Florida, Texas, Georgia** — high consumer volume, and together they cover opt-out, federal-election, unlimited-homestead, aggregate-cap and just-amended regimes. **Provisional**: the design-partner firm's state, once known, amends this set. | Proposed |
| [0018](0018-sqs-queue-and-worker-lambda-over-step-functions.md) | v1 async pipelines are an **SQS queue + one worker Lambda**, with the job record in the case table as the API's single status truth — Step Functions rejected for v1 on the local-story criterion (its ASL semantics execute only in the cloud) and because a one-state machine orchestrates nothing. Carries the reopen triggers (15-minute ceiling, a real DAG). | Accepted |
